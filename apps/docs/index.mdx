The Redesign Health platform is a healthcare-focused monorepo built on **Nx 22**. It powers a suite of applications for company building, advisor networking, and internal tooling — all backed by a unified design system and shared infrastructure.

The frontend runs on **React 19 + Vite** with **Chakra UI v3** for the component layer. The backend is a **Spring Boot** service (Java 17) with an Express mock server for local development. Everything is organized as Nx projects with enforced module boundaries, distributed caching, and automated code generation.

## Technology stack

| Layer | Technology |
| :--- | :--- |
| Build system | Nx 22 with distributed caching |
| Frontend | React 19 + Vite |
| UI components | Chakra UI v3 |
| Language | TypeScript 5 (strict mode) |
| Backend | Spring Boot (Java 17), Express mock server |
| State management | TanStack Query (server), Zustand (client) |
| Testing | Jest/Vitest, Playwright, Storybook + Chromatic |
| Linting | ESLint + Prettier |
| CI/CD | Nx Cloud, Chromatic visual regression |
